Import from Google Photos

  1. On a computer, open takeout.google.com, tap Deselect all, then tick only Google Photos.
  2. Next step: Send download link via email, Export once, file type .zip, size 50 GB. Create export.
  3. When Google's email arrives, download every part and put them all in Files › Photos › Import.
  4. Tap Import now. Dates, places, descriptions and albums come across. Running it again is safe.
